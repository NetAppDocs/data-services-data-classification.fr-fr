Pour que la date de dernier accès à vos fichiers ne soit pas modifiée par les analyses de NetApp Data Classification, configurez l'utilisateur Active Directory avec les autorisations d'écriture des attributs dans CIFS ou les autorisations d'écriture dans NFS. Si possible, configurez l'utilisateur Active Directory comme membre d'un groupe parent de l'organisation disposant des autorisations d'accès à tous les fichiers.
