= Déployez NetApp Data Classification avec VMware Open Virtual Appliance
:allow-uri-read: 
:no-hardbreaks: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Déployez NetApp Data Classification dans un environnement VMware vSphere sur site à l'aide d'une Open Virtual Appliance (OVA) prévalidée, un package géré qui simplifie l'installation et l'exploitation.

Cette méthode est recommandée pour les nouveaux déploiements basés sur VMware.



[[prerequisites]]
== Prérequis

Avant d'utiliser le fichier OVA pour installer Data Classification, vous devez disposer des éléments suivants :

* Un environnement vSphere VMware
* Une adresse IPv4 statique attribuée à l'appliance
* Serveurs DNS accessibles depuis le réseau cible
* Accès SSH activé sur l'appareil
* link:https://mysupport.netapp.com/site/user/registration["NetApp Support Site Identifiants"] pour télécharger le programme d'installation




[[deploy-the-ova-in-vmware-vsphere]]
== Déployez l'OVA dans VMware vSphere

. Téléchargez le fichier OVA depuis link:https://mysupport.netapp.com/site/products/all/details/cloud-data-sense/downloads-tab/["Site de support NetApp"^]. Choisissez l'appliance OVA adaptée à votre environnement :
+
|===
| Appareil OVA | Taille de production | limite d'analyse des fichiers 


| `DataClassification-<version>-L.ova` | Charge de travail de production standard : 16 CPUs, 64 GB RAM, 500 GB disk | 250 millions de fichiers 


| `DataClassification-<version>-XL.ova` | Charge de travail de production importante : 32 CPU, 128 Go de RAM, 1 To de disque | 500 millions de fichiers 
|===
. Ouvrez le client vSphere. Cliquez avec le bouton droit sur le cluster ou l'hôte cible, puis sélectionnez *Déployer le modèle OVF* > *Créer une VM à partir d'OVA*.
. Téléversez le fichier OVA que vous avez téléchargé à l'étape 1.
. Spécifiez le *nom de la machine virtuelle* ainsi que le centre de données cible, l’hôte ou le cluster et le datastore.
. Acceptez le NetApp End User License Agreement.
. Personnalisez le modèle. Vous devez fournir les informations suivantes :
+
** **Nom d'hôte** - le nom de l'appareil
** **Adresse IPv4** - l'adresse IPv4 statique de l'interface de gestion
** **Masque de sous-réseau IPv4** - par exemple 255.255.255.0
** **Adresse de la passerelle IPv4** - la passerelle par défaut
** **DNS principal** - le résolveur DNS requis
+
Vous pouvez également ajouter, en option, le **DNS secondaire** et, sous forme de listes séparées par des virgules, les **domaines de recherche** (par exemple, `corp.local,lab.local`) et les **serveurs NTP**.



. Définissez le *mot de passe Admin* pour l'utilisateur Linux par défaut.
+

NOTE: Ce mot de passe sert à l'accès root, à l'accès SSH et à l'administration système. Conservez le mot de passe en lieu sûr.

. Consultez le résumé. Sélectionnez *Terminer* pour déployer.
. Une fois le déploiement terminé, allumez la machine virtuelle.




[[install-data-classification]]
== Installer la classification des données

. Téléchargez le logiciel de classification des données depuis le link:https://mysupport.netapp.com/site/products/all/details/cloud-data-sense/downloads-tab/["Site de support NetApp"^].
+
Sélectionnez le fichier nommé *DATASENSE-INSTALLER-<version>.tar.gz*.

. Extrayez l'archive d'installation sur l'hôte VM en exécutant  `tar -xzf DATASENSE-INSTALLER-<version>.tar.gz`.
. Extrayez l'archive d'installation sur la machine hôte.
. Dans la console, sélectionnez *Gouvernance > Classification*.
. Sélectionnez *Déployer la classification*.
+
image:screenshot-deploy-classification.png["Une capture d'écran de la sélection du bouton pour activer la classification des données."]

. Sélectionnez l'option *Deploy* appropriée pour le type d'instance : cloud ou sur site.
. La boîte de dialogue « Déployer la classification des données sur site » s'affiche. Copiez la commande fournie (par exemple `sudo ./install.sh -a 12345 -c 27AG75 -t 2198qq`) dans un fichier texte pour une utilisation ultérieure. Sélectionnez *Fermer* pour fermer la boîte de dialogue.
. Utilisez SSH pour vous connecter à l'appliance OVA en tant qu'utilisateur administrateur.
. Exécutez la commande d'installation que vous avez générée pour terminer l'installation et enregistrer le système auprès de votre organisation.
