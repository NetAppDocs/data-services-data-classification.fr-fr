= Personnalisez la définition des données obsolètes dans NetApp Data Classification
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Data Classification identifie les données obsolètes afin que vous puissiez trouver des opportunités d'économies et traiter les risques liés à la gouvernance. Personnalisez la définition des données obsolètes pour l'adapter aux besoins de votre organisation et identifiez les données obsolètes en fonction de leur dernier accès ou de leur dernière modification.

Les données obsolètes peuvent être définies en fonction de la date à laquelle elles ont été _consultées pour la dernière fois_ ou _modifiées pour la dernière fois_. Vous pouvez choisir une période allant de six mois à dix ans.

Par défaut, les données sont considérées comme obsolètes si leur dernière modification remonte à trois ans.

.Définir les données obsolètes
. Dans Classification des données, sélectionnez **Configuration**.
. Sur la page Configuration, sélectionnez l'onglet **Paramètres**.
. Sous l'en-tête Définition des données obsolètes, sélectionnez *Modifier*.
. Dans le menu déroulant **Propriété du fichier**, choisissez si vous souhaitez définir les données obsolètes en fonction de leur *Dernier accès* ou de leur *Dernière modification*.
. Choisissez la période pour la définition des données obsolètes.
. Sélectionnez **Enregistrer**.
